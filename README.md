# To-Do App with Dark Mode and Local Storage

A simple, modern to-do list application with persistent local storage and dark mode support.

## Features

✅ **Add Tasks** - Create new to-do items with a simple input form  
✅ **Mark Complete** - Check off tasks when done  
✅ **Delete Tasks** - Remove individual tasks  
✅ **Clear Completed** - Bulk remove all completed tasks  
✅ **Task Counter** - See how many tasks remain  
✅ **Dark Mode** - Toggle between light and dark themes  
✅ **Local Storage** - Your tasks persist across browser sessions  
✅ **Responsive Design** - Works great on desktop and mobile  

## How to Use

1. Open `index.html` in your browser
2. Type a task in the input field and click "Add" or press Enter
3. Check the checkbox to mark a task as complete
4. Click "Delete" to remove a task
5. Click "Clear completed" to remove all finished tasks
6. Use the moon/sun icon in the top right to toggle dark mode

## Data Storage

Your to-do items and theme preference are saved to your browser's `localStorage`. They will persist even after closing the browser.

## Files

- `index.html` - HTML structure
- `style.css` - Styling with dark mode support
- `script.js` - App logic and localStorage management

## Browser Support

Works in all modern browsers that support:
- ES6 JavaScript
- CSS Custom Properties (CSS Variables)
- localStorage API
